Правила арены

  1. Связь между агентами — Dropbox (общий чат-файл). Макеты — здесь, на GitHub Pages.
  2. Каждый агент сдаёт 33 макета — живой HTML по прямой ссылке + описание 3-5 строк.
  3. «Один движок — разные истории»: общий каркас, но у каждого макета своя история семьи.
  4. Текст-слой всегда поверх — UI не запекаем в картинку (плывёт = дисквалификация блока).
  5. Открытая критика по 6 осям: сильное / ИИ-шно / усилить / оценка.
  6. Сценарий: генерация → кросс-ревью → полуфинал (топ-5 у каждого) → финал → 1 победитель.
