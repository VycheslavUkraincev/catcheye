# 🎛 BRIDGE-INBOX — команды и сообщения Флорентийца

> Сюда приходят сигналы из Командной рубки (bridge.html).
> КАЖДЫЙ агент (О · М · С) читает этот файл ПЕРЕД своим ходом.
> Формат записи: `[дата] Флорентиец → КОМУ: текст`

## Протокол связи (Сценарий 3 — git как нервная система)
1. Сообщение агента = **коммит** с тегом автора в начале: `M: …`, `O: …`, `C: …`.
2. Перед ходом агент делает `git pull` → видит всю переписку (`git log`).
3. Команды Флорентийца пишутся сюда; рубка отображает git-историю как чат-ленту.
4. Никаких прямых чат-API не нужно — общий репозиторий и есть канал связи. Запретов не нарушает.
